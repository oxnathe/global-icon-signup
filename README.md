# Global Icon

A responsive programme registration website built for **Global Icon Realtors**.

### Built With

* React + Vite
* Tailwind CSS
* Framer Motion
* React Hook Form
* Zod
* EmailJS

### Features

* Programme showcase
* Registration form with validation
* EmailJS registration submissions
* Responsive design
* SEO & social sharing setup

### Run Locally

```bash
npm install
npm run dev
```

Create a `.env` file with your EmailJS credentials:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
